使用说明对方拿到之后，按这一页就能自己跑起来

CrossCheck 是装在自己电脑上的网页工具，不是一个已经部署好的网站。把仓库地址发给对方即可，不要把本机的 .env 一起发过去。对方用自己的 API 密钥，费用记在对方账号上。密钥可以在网页里填，也可以写成文件。百炼那一把密钥默认同时给 Kimi、千问和智谱用，也可以拆成各填各的。

01 · 拿到之后

把仓库地址发过去，对方在自己电脑上运行

仓库地址：https://github.com/2024201542/cursor_datalab。如果仓库是私有的，要先在 GitHub 上把对方加为协作者，否则对方打不开。

不要发送 .env，也不要把密钥写进微信或邮件。 这个文件里是你自己的 DeepSeek 和百炼密钥。对方用你的密钥跑分类，费用从你的账号扣。仓库已经忽略了这个文件，git clone 不会把它带上。output/ 里的历史结果也不用发，对方自己运行会重新生成。
1

安装 Python

需要 Python 3.10 或更高。装好后在终端里执行 python --version 能看到版本号。Windows 上如果提示找不到命令，安装时勾选 “Add python.exe to PATH”，或改用 Anaconda / Miniconda 的终端。

2

克隆仓库

git clone https://github.com/2024201542/cursor_datalab.git
cd cursor_datalab

没有装 git 时，可以在仓库页面点 Code → Download ZIP，解压后进入那个文件夹。两种方式拿到的都是同一套代码，都不含密钥。

3

安装依赖

pip install -r requirements.txt
pip install python-docx pymupdf

第二行是读 Word 和 PDF 用的。只做表格里的短文本分类可以不装，但年报和上传标准文档会用到。

4

启动网页

python -m streamlit run app.py

浏览器打开 http://localhost:8501。这个地址只在对方自己的电脑上有效，别人的浏览器打不开你正在跑的这一份。关掉终端，网页就停了。想给实验室里的人一起用，每个人都在自己电脑上执行上面的命令。

5

先不配密钥也可以看界面

到「④ 运行与结果」打开 mock 模式，不调用真实接口，只走通流程。要得到真实分类结果，再按下一节填入自己的密钥。

02 · 密钥

两把就够用。百炼那把可以共用，也可以拆开。

打开网页后进入 ① 模型配置，往下翻过模型表格，最下面有一块标题是 API Key。密钥只写在这里，或者写在项目根目录的 .env 里。模型表格中的「Key 环境变量」是这个密钥的名字，不是密钥本身。

输入框是密码框，已经保存的密钥不会显示出来，所以看起来是空的。旁边如果写着「已配置（…后四位）」，说明这台电脑上已经有了。要更换，就把新密钥粘贴进去再点「保存 Key」。留空再点保存，表示保持原样、不修改。保存之后写进本机的 .env，下次打开还在，也不会被提交到仓库。

现在仓库里默认怎么接

投票模型是 DeepSeek、Kimi、千问，仲裁模型是智谱 GLM。Kimi、千问、GLM 三行的「Key 环境变量」都写成了 DASHSCOPE_API_KEY，接口地址都是阿里云百炼。网页按这个名字去重，所以只出现一个百炼输入框，填进去的那一把同时给这三个模型用。这是有意这样配的：百炼上可以开通多家的模型，一把密钥就能调。

推荐做法：先申请两把，在网页里填

DeepSeek

DEEPSEEK_API_KEY

打开 platform.deepseek.com，注册后创建 API key。只给表格里的 deepseek 这一行用。

阿里云百炼

DASHSCOPE_API_KEY

打开 bailian.console.aliyun.com，创建 API key。在模型广场确认能调用 kimi-k2.6、qwen3.7-plus、glm-5.3，没有开通的模型要先开通。这一把同时给 Kimi、千问、GLM。

两把都粘贴到对应输入框，点 保存 Key，再点 测试所有模型连通性。每一行都成功，就可以去运行页分类。测试失败时，先看是密钥错了、模型没开通，还是网络访问不了对应的接口。

可以分开填，页面就是按「名字」决定共不共用

密钥输入框的数量，等于模型表格里「Key 环境变量」这一列有多少个不同的名字。三个模型都写 DASHSCOPE_API_KEY，就只有一个框。把某一行改成别的名字，下面就会多出一个框，这一行不再读那把百炼密钥。

名字只是本机 .env 里的标签，可以自己起。改完表格后，到左侧栏点 保存，模型地址和名字才会写入配置文件。密钥仍要点下面的「保存 Key」，侧边栏那个保存按钮不写密钥。

情形一：还是用百炼，但想各备一把密钥

比如一个百炼账号只开了千问，另一个账号开了 Kimi 和 GLM。在模型表格里把它们的「Key 环境变量」改成不同名字，接口地址可以保持百炼不变：

模型接口地址保持把「Key 环境变量」改成

qwen同上QWEN_API_KEY
glm同上GLM_API_KEY

保存配置后，API Key 区会变成三个框。每个框粘贴对应账号的百炼密钥，再点「保存 Key」。DeepSeek 仍然单独用 DEEPSEEK_API_KEY。

情形二：不用百炼，改走各家官方接口

这才是真正换供应商。除了密钥名字，还要改「接口地址」和「模型」列，并在对应平台开通那个模型。

想换成在表格里改什么密钥去哪里申请
Kimi 官方把现有 kimi 那一行取消勾选。把已经写好、默认关闭的 kimi-official 勾上启用。它的地址是 https://api.moonshot.cn/v1，密钥名字是 MOONSHOT_API_KEY。官方接口当前限额很低（同时 1 个请求、每分钟 3 次），量大时仍建议走百炼。platform.moonshot.cn
智谱官方仲裁模型 glm 的接口地址改为 https://open.bigmodel.cn/api/paas/v4，模型名改成你账号里实际有的型号，「Key 环境变量」改为 ZHIPU_API_KEY。百炼上的 glm-5.3 这个名字在智谱官方不一定存在，要以控制台里的模型名为准。open.bigmodel.cn
千问官方 / 其他中转改 qwen 那一行的接口地址、模型名和密钥名字。任何 OpenAI 兼容接口都可以，接口类型保持 openai。对应平台的控制台

改完：左侧栏保存配置 → 在新出现的输入框里粘贴密钥 → 保存 Key → 再测一次连通性。

不想用网页时，直接写 .env

在项目根目录（和 app.py 同一层）新建文本文件，文件名就是 .env。默认两把密钥时写成：

DEEPSEEK_API_KEY=这里换成自己的DeepSeek密钥
DASHSCOPE_API_KEY=这里换成自己的百炼密钥

拆开填时，左边的名字必须和模型表格里「Key 环境变量」完全一致，例如：

DEEPSEEK_API_KEY=自己的DeepSeek密钥
KIMI_API_KEY=给Kimi用的百炼密钥
QWEN_API_KEY=给千问用的百炼密钥
GLM_API_KEY=给智谱用的百炼密钥

保存文件后重新运行 python -m streamlit run app.py。不要把这个文件提交到 git，也不要发给别人。

03 · 能做什么

现在这套系统已经能做的事

类别和标准都写在配置里，代码不针对某一个数据集。换任务不用改程序。

分类

短文本分到一个或几个类别

客服消息意图、新闻标题、股吧情绪、年报里的一段话、美联储表态，都用同一套流程。默认一条文本一个类别；也可以开启多标签（一条同时属于几类），或把类别写成「一级/二级」做层级分类。

对话

多轮对话

一行一句（会话编号、角色、内容），或一行一段用「角色：内容」写好的对话。可以整段一个类别，也可以只判断某一句并带上前文。

长文档

年报按段分类

上传 PDF、Word、网页或 TXT。按章节切开，丢掉目录和套话，可按章节、关键词筛选，再逐段分类，并汇总成每份文档的占比和净语调。

标准

分类标准可以变

新建任务、从 Word/PDF 或已标注数据生成标准草稿、检查标准里的冲突、每次修改自动留版本，还能恢复旧版本。

质量

知道结果可不可信

有人工标签时给出准确率。分歧的样本交给人审。历史页可以对比两次运行差多少、是不是偶然，并看标准改了哪里。

成本

跑之前能估价

按模型和字数预估费用。可以只先问便宜的模型，一致就不再问其余模型。已经问过的文本会进缓存，改标准后只对受影响的部分重新付费。

校准

让置信度说真话

模型自报的 90% 实际常常只有 65% 对。用一次带人工标签的运行校准后，可以按「想要多高的准确率」自动算出采纳门槛。

协作

分歧样本的几种讨论方式

多轮辩论、魔鬼代言人、只看理由或只看结论的复核、要求引用原文、多个模型组成评审团代替单个仲裁。都是开关，默认关闭。

还不能做：三级及以上的层级；把很长的对话先摘要再分类；扫描版 PDF（没有文字层的图片）；从年报里按字段抽取「减排目标是多少」这种结构化信息；输入股票代码自动下载年报。这些在介绍页的路线图里，还没有做。
04 · 怎么实现

多个模型各判一次，不一致就交给人

分类标准（类别定义、正例、反例、边界规则）会写进提示词。每个启用的模型独立回答，互不知道别人的结论。程序比较它们的标签：

  1. 全部一致：直接采纳。这是质量比较高的信号，但不是证明，所以审核页仍然可以抽检。
  2. 不一致：默认把这条标成「需人工审核」，并给出一个建议标签。也可以改成先交叉复核再投票，或先交给仲裁模型（现在是 GLM）。策略在运行页切换。
  3. 可选的省钱方式：级联。先只问列出的模型，它们一致（还可以再要求置信度够高）就采纳，不再问贵的模型。
  4. 可选的增强：如果有同一任务的已标注数据，可以检索最相似的例子放进提示词，或训练一个本地小模型参加投票。没有这类数据就跳过，不影响基本分类。
  5. 可选的校准：拿一次带人工标签的运行，统计每个模型在每个类别上容易把什么错判成什么（混淆矩阵），再把自报置信度换算成真实正确率。之后每条样本都能算出「多数答案是对的」的概率，高于门槛就采纳，即使首轮有分歧；首轮一致但概率低的也交给人。

实测哪些有用。校准本身很有效：模型的置信度误差（ECE）从 0.06–0.36 降到 0.03–0.14。按校准后的概率挑自动采纳的样本，在投票者里有本地小模型时，同样的自动采纳比例准确率高 3.6–6.0 个百分点；只有几个相似的大模型时没有帮助。换聚合算法（按类别加权、Dawid-Skene、MACE、GLAD 等）差别都在 3 个百分点以内。在股吧情绪的分歧样本上，多轮辩论、魔鬼代言人、对照式复核、评审团、证据引用、多次采样都没有显著提升，最多多对 2 条；多轮辩论只让模型变得更一致，并没有更正确。所以默认仍是「分歧交给人」。

模型输出被要求是一行 JSON：标签、置信度、理由。理由里的引号有时会把 JSON 弄坏，程序会再按字段把标签抠出来。每次调用的原文和回复会缓存在本机，同样的提示词不会重复扣费。

密钥的读取顺序是：配置里如果直接写了密钥就用那个（不建议）；否则用「Key 环境变量」这个名字，到环境变量和 .env 里取值。所以改表格里的名字，就是在改「这一行模型去读哪一把密钥」。

一次运行会在 output/web/时间戳/ 写下结果、费用和当时的配置快照（快照里没有密钥）。对话和年报还会多一个文件，用来在审核页还原气泡和章节，而不是只显示送给模型的那一大段提示词。

05 · 怎么操作

六个页面，按这个顺序用

页面 ① · 模型配置

先让模型能连上

表格里可以改启用开关、角色（投票、仲裁或评审团）、接口地址、模型名、价格、并发。评审团成员只在分歧需要仲裁时使用，有评审团就不再用单个仲裁模型。价格只影响页面上的费用估算，不影响厂商实际怎么扣费。改完到左侧栏点保存。

密钥按上一节填写并测试。连通性全部成功再往下走。

页面 ② · 分类任务

告诉模型「什么叫这一类」

左侧栏的下拉框是任务列表，每一项是 configs/ 里的一个文件。仓库里已经有客服消息、新闻、股吧情绪、年报气候段落、美联储表态。选中一个，这一页会显示它的类别和规则。

做新任务：左侧栏「新建分类任务」。可以从空白开始（仍沿用现在的模型），或复制当前任务。然后：

  • 有书面口径：展开「生成标准草稿」，上传 Word / PDF / TXT，或直接粘贴。先预览，确认后再替换。
  • 只有标好的样本、没有成文标准：草稿来源选「从已标注数据归纳」。
  • 点「标准体检」，看有没有互相打架的规则和坏例子。
  • 左侧栏写一句修改说明再保存。标准真有变化时会自动留下一个版本，可以在本页对比和恢复。
  • 一条文本可能同时属于几类：打开「多标签」，设每条最多几个标签。人工标签写成「积极|消极」或「积极、消极」都可以。
  • 类别有两级：把类别名写成「投诉/物流」「投诉/质量」这样，再打开「层级分类」。结果会多一个一级类准确率。

本页底部有验证步骤：新任务先抽 100～200 条人工确认，再分成调参集和验证集。只在调参集上反复改标准，验证集留到最后跑一次。100 条样本、准确率大约 80% 时，误差大约 ±8 个百分点，差两三个点看不出来。

页面 ③ · 训练数据（可以不做）

没有历史标注就跳过

这里的文件是「同类任务里已经标好的例子」，不是这次要分类的新数据。有它才能打开动态示例和本地小模型。标签必须是当前任务里存在的类别。评估时如果待测文本也在这份文件里，页面会提醒准确率会偏高。

动态示例默认用字符相似度，在本机找例子，不花钱。可以改成向量检索（百炼的文本向量，和千问同一把密钥，大约 0.5 元 / 百万 token）。相同文本会缓存在这台电脑上，不重复计费。在股吧和美联储表态上，向量找回来的例子比字符相似度更接近标准答案。另一个开关是审核后自动入库：人工审核页确认一条，就把它写进这份训练数据，下次分类会参考这个人工标签。默认关闭。

页面 ④ · 运行与结果

顶部先选数据是哪一种

普通文本。上传 CSV、Excel 或 JSONL，或选 data/ 里的文件。指定哪一列是正文、哪一列是编号。有人工标签时指定标签列，跑完会出准确率。示例：data/sample.csv、data/gold.csv。

多轮对话。选「一行一句」时要有会话编号、角色、内容；customer / agent 会当成用户 / 客服。选「一行一段」时，单元格里按行写「用户：……」「客服：……」。可以整段一个类别，或只分类某一个角色的句子。太长会保留最近的内容。示例：data/sample_dialogue.csv。

长文档。上传一份或多份 PDF、Word、网页、TXT。先看切出来多少段，再用章节和关键词缩小，然后分类。结果区会按文档汇总。示例：data/sample_report.txt。扫描版 PDF 会提示读不出文字。

三种都一样：先点「预估调用次数和费用」，再点开始运行。第一次建议把「只处理前 N 条」设成 20，确认标签和费用正常再跑全量。运行中关掉页面也不怕，同样的调用会命中缓存。

「🧪 高级」折叠区（不懂可以不动，全部关闭时和以前完全一样）：

  • 校准文件与后验概率门槛：在历史页生成，见页面 ⑥。
  • Self-Consistency：每个模型多答几次取多数，费用按次数成倍增加，可以只选一两个模型。
  • 证据引用：要求模型逐字引用原文，引用在原文里找不到的判断权重打折。审核页会显示引用。
  • 复核最多几轮、复核时看到的他人意见、魔鬼代言人：只在分歧策略选「交叉复核」时起作用。
  • 评审团采纳门槛：评审团里同意同一个标签的比例达到多少才采纳。

这些选项都会让预估费用变化，先点预估再运行。

页面 ⑤ · 人工审核

处理模型没把握的，也抽查模型都同意的

选择刚才那次运行。范围可以是「需人工审核」、全部分歧、「优先标注」（先看模型最没把握、而且内容不重复的），或从「首轮一致通过」里随机抽几条。在年报气候数据上，优先看的前 20 条能抓住大约一半判错，随机抽 20 条平均只抓住大约一成。逐条确认，或在表格里批量填写。对话会显示成气泡，理由里逐字引用到的句子会标出来。年报会显示章节、页码和上下段。

确认过的样本可以追加进金标准或训练数据，下一次就能用来评估或当作示例。

页面 ⑥ · 历史与对比

改了标准或换了模型之后，看有没有真的变好

每次运行都有时间、数据、费用、用的哪一版分类标准。勾选两次以上，可以看准确率差多少、McNemar 检验是否只是随机波动，以及两版标准的逐条差异。

页底的漂移监控把同一任务按时间排开。最近一次的人工比例升高 8 个百分点、准确率下降 5 个百分点，或标签分布变化达到 0.15，会提示。两次用的标准不同时会写明，避免把改口径误当成数据变了。

规则建议读取某次运行里模型意见不同的样本，归纳边界，给出可以直接追加的规则。追加之后还要在左侧栏保存，才会写进文件。

校准与门槛：选一次带人工标签的运行（最好 150 条以上），页面会比较十几种聚合方式、显示每个模型校准前后的置信度误差，并让你拖动「目标准确率」，给出推荐门槛和能自动采纳的比例。达不到目标时会直接说能达到多少。点「保存校准文件并用于当前配置」后，下一次运行就按这个门槛决定哪些自动采纳。类别改过之后要重新校准。

优先审核和可疑标签不调用模型。可疑标签是几个模型很有把握地给出了和标准答案不同的标签，可能是标错了，也可能是模型一起错了，只列出来，不会自动改。搜索规则会调用模型、产生费用：在一部分样本上试新的边界规则，另一部分只用来检查有没有真的变好。在股吧的 36 条上试过，用来挑选的那一部分看起来更好，留出来检查的那一部分和原来一样，所以没有改规则。

06 · 常见问题

对方最容易卡住的地方

密钥框是空的，是不是没保存上？

密码框本来就不回显。看标题右侧是不是「已配置（…四位）」。是的话就已经在 .env 里。

只填了百炼，DeepSeek 失败

DeepSeek 不走百炼。必须再填 DEEPSEEK_API_KEY，或者在表格里关掉 deepseek 那一行。

改了密钥名字，旧密钥还在生效吗？

不会自动跟着走。旧名字下的密钥还在 .env 里，但模型已经去读新名字。新框显示「未配置」时，要重新粘贴并保存。

侧边栏保存了，为什么密钥丢了？

侧边栏保存的是类别、规则、模型地址，不包含密钥。密钥只由「保存 Key」或手改 .env 写入。

连通性测试很慢或超时

先确认本机能打开对应网站。公司网络或校园网有时拦截境外接口。DeepSeek、Kimi 官方、百炼是不同的地址，可能只有其中一个不通。

准确率和我预期差很多

先看分类标准，而不是先换模型。用验证向导做一小批人工标签，在历史页对比改标准前后。100 条上差几个点，往往还不能下结论。

网页打不开 localhost:8501

终端里那条命令必须还在跑。换了一台电脑或把地址发给别人是打不开的，对方要在自己的电脑上启动。

向量检索和自动入库要不要开？

字符检索免费，向量检索更准一点但会按 token 计一点费，结果会缓存。自动入库适合你希望「审过的样本下次还能用」的时候，在训练数据页打开。多标签任务不会自动写入。

要不要打开辩论、评审团这些高级选项？

先别开。在我们测过的数据上它们几乎没有提升，却会多花几倍的钱。想试的话，在自己任务的金标准上开一个、跑一次，到历史页和不开时对比。

想先零费用看流程

运行页打开 mock 模式。它不访问任何厂商，结果不能当成真实准确率。
